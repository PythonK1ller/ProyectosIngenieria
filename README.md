🧪 Filosofía

Este repositorio no busca únicamente almacenar código.

La idea es utilizarlo como un laboratorio personal de ingeniería: probar ideas, cometer errores, aprender de ellos, documentar lo aprendido y convertir los experimentos exitosos en soluciones más sólidas.

Construir → probar → medir → aprender → mejorar.
